# 「分享到 App」設定步驟（約 5 分鐘）

在 IG、小紅書、Safari、相簿按「分享」→ 選這個 App →「加到購物清單／想去清單」。
這需要一個 **Share Extension（分享延伸功能）target** 和 **App Group**，這兩個要在 Xcode 裡點選建立
（手動改專案檔容易弄壞簽署設定，所以程式碼都寫好了，只剩下面幾步）。

沒有做這些步驟時，App 照常可以編譯、使用，只是分享選單裡不會出現這個 App。

## 1. 建立 Share Extension target

1. Xcode 選單 **File › New › Target…**
2. 選 **iOS › Share Extension** → Next
3. Product Name 填 **ShareExtension**，Language 選 Swift → Finish
4. 問要不要 Activate scheme 時按 **Activate**（之後切回 MobileCLIPExplore 的 scheme 就好）

Xcode 會建立一個 `ShareExtension` 資料夾，裡面有 `ShareViewController.swift`、`MainInterface.storyboard`、`Info.plist`。

## 2. 換成寫好的程式

1. 把 `ShareExtension/ShareViewController.swift` 的內容，整個換成這個資料夾（`ShareExtensionSource`）裡的 `ShareViewController.swift`。
2. 刪掉 `ShareExtension/MainInterface.storyboard`（Move to Trash）。
3. 打開 `ShareExtension/Info.plist`，把 `NSExtension` 整段換成這個資料夾 `Info.plist` 裡的 `NSExtension`
   （重點：用 `NSExtensionPrincipalClass` = `ShareViewController`，**不要**有 `NSExtensionMainStoryboard`）。
   如果 Xcode 沒有產生 Info.plist（設定在 target 的 Info 分頁），就在 Info 分頁照同樣的內容設定。
4. 在左邊專案列表點 `MobileCLIPExplore/Shared/SharedInbox.swift`，右邊 **File inspector › Target Membership**
   把 **ShareExtension** 也勾起來（MobileCLIPExplore 原本就有勾）。
5. ShareExtension target 的 **General › Minimum Deployments** 設成和 App 一樣（iOS 17.3）。

## 3. 加上 App Group（兩個 target 都要）

1. 點 **MobileCLIPExplore** target › **Signing & Capabilities** › 左上 **+ Capability** › **App Groups**
2. 按 **+**，填 **group.com.elaine.MobileCLIPExplore**（要和 `SharedInbox.swift` 裡的 `appGroupId` 一模一樣）
3. 點 **ShareExtension** target，做同樣的事，勾選同一個 group。
4. ShareExtension 的 Team 選和 App 一樣的 Team。

> App Group 需要付費的 Apple Developer Program 帳號；用免費的個人帳號（Personal Team）時 Xcode 可能不給加。
> 沒有 App Group 時分享視窗會顯示「App 還沒設定 App Group」，App 其他功能不受影響。

## 4. 試試看

1. 切回 **MobileCLIPExplore** scheme，安裝到手機。
2. 打開 IG 或相簿的一張商品截圖 › 分享 › 在 App 列表找到 **加到清單**（第一次可能要按「更多」把它打開）。
3. 選「加到購物清單」→ 顯示「已收到！」後自動關閉。
4. 打開 App（電腦後端開著、同一個 Wi-Fi）→「我的」›「購物清單」上方會顯示整理結果。

## 運作方式

- 分享視窗只把截圖（縮到長邊 2000 px）或網址、文字存進 App Group 的共用資料夾，不存進相簿。
- App 回到前景、或連上電腦時整理：辨識文字 → Agent 整理商品或地點 → 存進清單。
  整理完就刪掉共用資料夾裡的檔案；清單上「查看截圖」用的縮小副本存在 App 自己的資料夾。
- 連不上電腦時留著，清單頁會顯示「等待整理 N 張」，連上後自動繼續。
